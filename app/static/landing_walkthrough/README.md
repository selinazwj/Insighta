# Landing-page walkthrough frames

These JPEGs are close-ups of Insighta's actual Jinja product pages using an
isolated, seeded demonstration database. They are UI-state sequences composed
for the landing-page player, not a recording of a customer session.

- `audience-0..2`: publishing wizard, audience step; set age and state.
- `verification-0..2`: basic, professional, then Didit verification requirement.
- `screening-0..2`: draft, edited wording, then the approved screener view.
  The approved view was prepared in the local capture fixture.
- `review-0..2`: pending response, review options, then a manual reject decision.

Names, `.invalid` addresses, scores, and counts are sample data. No production
accounts, identity documents, paid AI requests, or payment actions were used.

The player uses the existing landing-page fonts and color variables. Motion
stops when off-screen or hidden, can be paused, and is disabled initially for
`prefers-reduced-motion`. Do not replace these frames with customer data.
