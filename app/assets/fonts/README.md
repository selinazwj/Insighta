# Invoice font

Noto Sans SC, distributed under the accompanying SIL Open Font License.
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

`NotoSansSC-Regular.ttf` is the static weight-400 instance of `NotoSansSC[wght].ttf`, generated with fontTools `instantiateVariableFont(font, {"wght": 400})`. No glyphs were removed. PDF generation embeds only the glyphs actually used in each document. This asset is used server-side; it is not a web-font download.
